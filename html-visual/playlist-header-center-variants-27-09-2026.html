TẦNG 3/4 • CALL TREE

⚡ 3. Luồng Gọi Hàm Khi Thao Tác

Mọi hành động Đổi tên, Đổi bìa hay Xóa playlist đều tận dụng 100% API và Socket sync sẵn có. Khi xóa xong, hệ thống tự động fallback về tab trước đó mà không bao giờ bị trắng màn hình.

📄 Call Tree Hành Động
CALL TREE
onInlineRename(newName)
└── usePlayerStore.getState().renamePlaylist(id, newName)
└── PUT /api/playlists/:id/rename
└── fetchPlaylists() + Broadcast WS "playlist_updated"
onDeletePlaylist(id)
└── ConfirmModal.open()
└── usePlayerStore.getState().deletePlaylist(id)
└── DELETE /api/playlists/:id
└── setActivePlaylist(null) -> Chuyển về màn Mixed mượt mà
TẦNG 4/4 • THUẬT TOÁN & LOGIC

🧠 4. Thuật Toán Lọc Nhanh Trong Playlist

Nếu triển khai Hướng B hoặc Hướng D (Bộ lọc Slice vs Track), logic lọc diễn ra hoàn toàn trên bộ nhớ đệm (in-memory), độ trễ 0ms (instant render).

📄 Pseudocode Bộ Lọc Nhanh
LOGIC
function getFilteredPlaylistItems(items, filterMode, searchQuery):
let result = items
if filterMode === "slices_only":
result = result.filter(it => it.segment != null)
else if filterMode === "tracks_only":
result = result.filter(it => it.segment == null)
if searchQuery:
result = fuzzySearch(result, searchQuery)
return result

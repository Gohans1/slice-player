TẦNG 2: COMPONENT LEVEL

Giao Tiếp Giữa Các Component & Hooks

PlaylistTableView làm chủ toàn bộ state kéo thả (draggedIdx, dragOverIdx). Virtualized body nhận virtualizerRef để tra cứu vị trí thả theo thời gian thực khi đang cuộn trang.

Window listener được kích hoạt riêng biệt khi draggedIdx !== null để đảm bảo con trỏ bay ra rìa viewport vẫn bắt được event.

<PlaylistTableView> ├── State: draggedIdx, dragOverIdx ├── Refs: draggedIdxRef, dragOverIdxRef, virtualizerRef ├── Window Listeners: │ window.on("dragover") -> checkAutoScroll(e.clientY) │ window.on("drop") -> handleGlobalDrop() ├── <TableContainer role="table"> │ ├── <TableHeader role="row" aria-rowindex={1}> │ │ └── onDrop -> commitReorder(draggedIdx, 0) │ └── <VirtualizedTableBody> │ ├── useWindowVirtualizer({ │ │ rangeExtractor: giữ draggedIdx không bị unmount │ │ }) │ └── <Row draggable />

TẦNG 4: ALGORITHM & PSEUDOCODE

Thuật Toán Tính Vận Tốc & Giữ Pin Node

Vận tốc động: Càng dí sát mép màn hình (hoặc vượt ra ngoài), tỷ lệ ratio càng lớn, tốc độ cuộn tăng dần từ 8px/frame lên đến 28px/frame giúp cuộn 100 bài hát chỉ trong ~1.5 giây.

Bảo vệ session: rangeExtractor hợp nhất danh sách index mặc định với draggedIdx.

// 1. Ghim index đang kéo trong DOM dù danh sách có cuộn đi đâu: function rangeExtractor(range): active = defaultRangeExtractor(range) if draggedIdx is valid and not in active: active.push(draggedIdx) active.sort((a, b) => a - b) return active // 2. Tính toán gia tốc cuộn dựa trên vị trí chuột: function checkAutoScroll(clientY): topZone = 120px bottomZone = 140px (né PlayerBar) if clientY < topZone: ratio = clamp((topZone - clientY) / topZone, 0, 1) speed = -(8 + ratio * 20) // Lên: -8px/f đến -28px/f startAutoScroll(speed) else if clientY > vh - bottomZone: ratio = clamp((clientY - (vh - bottomZone)) / bottomZone, 0, 1) speed = 8 + ratio * 20 // Xuống: 8px/f đến 28px/f startAutoScroll(speed) else: stopAutoScroll()

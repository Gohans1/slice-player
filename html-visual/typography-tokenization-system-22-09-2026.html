⚙️ 3. Định Nghĩa Tại index.css

Tận dụng sức mạnh của Tailwind CSS v4 @theme inline. Khi khai báo cặp --text-* và --text-*--line-height, compiler tự động sinh ra các class .text-* đi kèm line-height: var(--tw-leading, ...) mà không cần viết CSS thủ công.

@theme inline rem Units
📄 src/client/src/index.css
CSS
@theme inline {
+ --text-2xs: 0.75rem; # 12px (Floor tối thiểu cho badges & tags)
+ --text-2xs--line-height: 1rem; # 16px (Tỷ lệ 1.33x không bị dính chữ)
+ --text-xs: 0.8125rem; # 13px (Secondary body & compact UI)
+ --text-xs--line-height: 1.125rem; # 18px
+ --text-sm: 0.9375rem; # 15px (Body chính, inputs, track titles)
+ --text-sm--line-height: 1.375rem; # 22px
+ --text-base: 1.0625rem; # 17px (Desktop primary body)
+ --text-base--line-height: 1.625rem; # 26px
}

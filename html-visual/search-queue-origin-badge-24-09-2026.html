📁 1. Kiến Trúc State: Bổ Sung queueOrigin

Hiện tại Store usePlayerStore chỉ lưu playbackMode và activePlaylistPlayingId. Khi phát từ kết quả search, app đéo ghi nhớ ngữ cảnh tìm kiếm.

⚙️ 4. Pseudocode Quyết Định Badge

Thuật toán xác định text và icon cho badge tại PlayerBar: Đảm bảo khi xóa search hoặc bấm chọn playlist khác thì badge tự động hoàn nguyên.

PSEUDO
function getBadgeConfig(state):
if state.queueOrigin?.type == "search":
let query = state.queueOrigin.query
let count = state.queueOrigin.count
let prefix = state.isShuffle ? "🔀 🔍" : "🔍"
return {
label: `${prefix} "${query}"`,
tooltip: `Đang phát từ tìm kiếm: "${query}" (${count} bài)`,
style: "search-highlight"
}
else if state.activePlaylistPlayingId:
return { label: state.playlistName, style: "playlist" }
else:
return { label: getCategoryName(state.playbackMode), style: "default" }

TẦNG 4: ALGORITHM & LOGIC LEVEL

Tối Ưu Prompt AI & Trị Dứt Điểm CSS !important

Hàm getActiveTaxonomy loại trừ toàn bộ các category mang trạng thái off trước khi gửi payload lên classifier.dev, tiết kiệm token và tăng tốc đáng kể.

Khắc phục triệt để lỗi CSS Cascade: thẻ .x-jev-focus-bar có display: flex !important nên khi unhide phải dùng style.setProperty('display', 'none', 'important') kết hợp class .x-jev-hidden.

💡 Nâng cấp: Phân biệt rõ từ khóa function, return (đỏ cam), tên hàm (xanh), chuỗi (lam nhạt), biến và comment. Đọc code mượt mà êm ái như xem trong VS Code!

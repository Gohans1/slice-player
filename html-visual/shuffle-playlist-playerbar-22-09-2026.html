🗄️ 2. Truy Vấn Memberships Chuẩn SQL

Hàm `getPlaylistMemberships` cho phép gom tất cả các playlist chứa bài hát (dù bài hát đó nằm dưới dạng bài hát nguyên bản hay dưới dạng một slice đoạn cắt):

SQLite MIN(id) Aggregation
📄 src/server/db.ts
TS / SQL
export function getPlaylistMemberships(
trackId: string, segmentId?: string | null,
+ includeAllSegments = false
) {
+ if (includeAllSegments) {
+ return db.query(`
+ SELECT playlist_id, min(id) as item_id FROM playlist_items
+ WHERE track_id = $track_id
+ GROUP BY playlist_id
+ `).all({ $track_id: trackId });
+ }
// Các luồng lọc theo slice đơn lẻ giữ nguyên
}

⚡ 3. Nghe Tiếp Mượt Mà Không Ngắt Audio

Khi chọn playlist con, app sẽ nạp playlist đó vào queue, đặt bài hiện tại ở index 0, xáo trộn các bài còn lại. Nếu đang phát đúng bài đó thì không gọi `playSegment` để tránh reset audio về 0:00:

Zero Audio Jitter State Invariant
📄 src/client/src/store/usePlayerStore.ts
TS
if (keepCurrentTrack && get().activeTrack) {
+ const matchedItem = queueItems[matchIdx];
+ const remainingItems = queueItems.filter((_, idx) => idx !== matchIdx);
+ const finalRest = forceShuffle ? shuffleArray(remainingItems) : remainingItems;
+ queueItems = [matchedItem, ...finalRest];
+ set({ queue: queueItems, queueIndex: 0, isShuffle: true, activePlaylistPlayingId: playlistId });
+ const isCurrentlyPlayingThis = get().isPlaying &&
+ get().activeTrack?.id === matchedItem.track.id &&
+ get().activeSegment?.id === matchedItem.segment.id;
+ if (!isCurrentlyPlayingThis) {
+ await get().playSegment(matchedItem.segment, matchedItem.track, 0);
+ }
}

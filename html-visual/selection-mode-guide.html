CƠ CHẾ NÚT PLAY TRONG TRẠNG THÁI SELECTION MODE

Phân tích chuyên sâu luồng điều khiển, mã giả giải thuật, cấu trúc component và diff thay đổi.

Khi user kích hoạt selection mode để chọn hàng loạt track hoặc slice, mọi thao tác click play chỉ chuyển hướng thành toggle select, tuyệt đối không ngắt hay can thiệp vào audio đang phát.

Phần giải thích chi tiết kiến trúc điều khiển, mã giả giải thuật, sơ đồ tương tác thành phần và diff mã nguồn.

1. Mã giả giải thuật xử lý Click Play (Pseudocode)

on(clickPlayButton, targetItem)
  if useSelectionStore.selectedTrackIds.size > 0
    toggleItem(createSelectedItem(targetItem))
    updateSelectionCounter()
    return // Chặn đứng lệnh phát nhạc, giữ nguyên audio engine
  
  if targetItem is playing
    pauseAudio()
  else
    playTrackOrSegment(targetItem)

2. Cây luồng gọi hàm runtime (Runtime Call Tree)

user_clicks_play_button(track_or_slice)
│
├── useSelectionStore.getState().selectedTrackIds.size > 0 ?
│ │
│ ├── [YES: Đang trong Selection Mode]
│ │ ├── e.stopPropagation()
│ │ ├── createTrackSelectedItem(track) / createSliceSelectedItem(slice)
│ │ ├── toggleItem(selectedItem)
│ │ ├── BulkActionBar re-renders with fresh count
│ │ └── EARLY RETURN (usePlayerStore hoàn toàn đéo bị gọi)
│ │
│ └── [NO: Chế độ phát nhạc bình thường]
│ ├── playSegmentInMode(...) / playTrack(...)
│ ├── loadAudioBuffer()
│ └── updateActivePlaylistQueue()

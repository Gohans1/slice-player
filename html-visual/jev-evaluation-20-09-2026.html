📁 1. Cấp Độ Folder & Modules

Slice Player là kiến trúc full-stack nguyên khối nhỏ gọn chạy trên Bun. Server xử lý SQLite, yt-dlp và media stream. Client là React 19 + Zustand + Wavesurfer.

  • ▸ Nơi Jev có thể sống: Một service module con src/server/classifier.ts độc lập gọi HTTP sang classifier.dev.
  • ▸ Tuyệt đối không đụng: Client audio engine và Wavesurfer.js vì Jev đéo xử lý âm thanh.

🌲 3. Cấp Độ Function & Call Tree

So sánh cây gọi hàm khi import playlist YouTube.

  • ▸ Tránh được Bun.spawn(yt-dlp download) cho hàng tá video vô ích.
  • ▸ Tiết kiệm CPU generate waveform (peaks) cho các video rác.
// TRƯỚC (Không có Jev):
ingestYouTubeUrl()
  └── fetchMetadata()
        └── for each entry:
              ├── db.createTrack()
              ├── enqueueDownload()
              │     └── Bun.spawn(["yt-dlp", download])  <-- CHẬM, TỐN BĂNG THÔNG
              └── generatePeaks()                        <-- TỐN CPU

// SAU (Có Jev bulk-classify):
ingestYouTubeUrl()
  └── fetchMetadata()
        ├── classifierDev.bulkClassify(titles)           <-- 1 HTTP Call ~600ms
        │     └── Filter [score >= 0.8 && label == "music"]
        └── for each KEPT entry only:
              ├── db.createTrack(withSuggestedGenre)
              ├── enqueueDownload()                      <-- CHỈ TẢI BÀI ĐÚNG
              └── generatePeaks()
🧠 4. Cấp Độ Thuật Toán & Logic (Pseudocode)

Thuật toán gọi Jev theo chuẩn TypeSafe AI / classifier.dev với calibrated confidence score.

  • ▸ Sử dụng native fetch của Bun (không cần SDK cồng kềnh).
  • ▸ Fallback an toàn: Khi mất mạng hoặc Jev timeout, tự động giữ nguyên toàn bộ bài (ưu tiên recall).
// Thuật toán tiền lọc bằng Jev (classifier.dev)
async function filterMusicWithJev(titles: string[]) {
  try {
    const res = await fetch("https://classifier.dev", {
      method: "POST",
      headers: { "Content-Type": "application/json", "User-Agent": "slice-player/1.0" },
      body: JSON.stringify({
        labels: ["music song", "talkshow podcast vlog", "meme noise joke"],
        inputs: titles, // Tối đa 1000 tiêu đề trong 1 request duy nhất
        instructions: "Phân biệt bài hát âm nhạc thực thụ với các video nói chuyện, stream, hài kịch."
      }),
      signal: AbortSignal.timeout(4000)
    });

    const data = await res.json();
    return titles.map((title, i) => {
      const decision = data.results[i];
      // Nếu là music hoặc độ tin cậy thấp (<0.7) -> giữ lại (bias toward keeping)
      const shouldKeep = decision.label === "music song" || decision.confidence < 0.7;
      return { title, shouldKeep, label: decision.label, confidence: decision.confidence };
    });
  } catch (err) {
    // Ponytail & Fail-safe: Nếu mất mạng / lỗi API -> giữ toàn bộ, đéo làm rớt bài của user
    return titles.map(title => ({ title, shouldKeep: true, label: "unknown", confidence: 0 }));
  }
}

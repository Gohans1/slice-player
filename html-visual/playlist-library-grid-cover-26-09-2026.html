TẦNG 4/4 • LOGIC & SQL

🧮 Chọn ảnh bìa + truy vấn

Server trả sẵn 2 thứ cho client: cover_url (bìa m chọn tay) và mosaic_urls (tối đa 4 ảnh, mỗi bài chỉ lấy 1 lần, nên 1 bài bị cắt 3 slice đéo chiếm 3 ô).

✅ db.ts:166 đã bật PRAGMA foreign_keys = ON, nên ON DELETE SET NULL chạy thật: xóa bài đang làm bìa thì playlist tự quay về mosaic.

+9 SQL
+-- migration mới (user_version tiếp theo)
+ALTER TABLE playlists ADD COLUMN cover_track_id TEXT
+ REFERENCES tracks(id) ON DELETE SET NULL;
-- listPlaylists(): giữ query cũ, thêm 2 cột
SELECT p.id, p.name, …, COUNT(pi.id) AS item_count,
+ (SELECT thumbnail_url FROM tracks WHERE id = p.cover_track_id) AS cover_url,
+ (SELECT json_group_array(u) FROM (
+ SELECT t.thumbnail_url u FROM playlist_items x JOIN tracks t ON t.id = x.track_id
+ WHERE x.playlist_id = p.id AND t.thumbnail_url <> ''
+ GROUP BY t.id ORDER BY MIN(x.sort_order) LIMIT 4)) AS mosaic_urls
FROM playlists p LEFT JOIN playlist_items pi ON p.id = pi.playlist_id
GROUP BY p.id ORDER BY p.updated_at DESC, p.created_at DESC
